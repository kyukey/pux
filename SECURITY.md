# Security

## Reporting a vulnerability

Please report security problems privately from the [Security tab](https://github.com/kyukey/pux/security) with "Report a vulnerability", not in a public issue. A public report shows everyone the problem before a fix exists.

pux is maintained by one person, so I can't promise a response time, but I read every report and will fix real problems as soon as I can.

## Supported versions

Fixes go into the latest release, so please update to it before reporting.
